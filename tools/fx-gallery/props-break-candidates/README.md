# Breakable props: break-sound candidates

Candidates for the break sounds of breakable props (Task 10, steps 1-3). Nothing ships until Roi picks on `tools/fx-gallery/props-sounds-audition.html`. The `.ogg` files stay untracked; only this README and the audition page are committed.

## Sources and licence proof

- Every recording is from Freesound and **CC0 1.0** (public domain). The licence was verified per file on its own sound page (the page links `creativecommons.org/publicdomain/zero/1.0/`, shown as "Creative Commons 0"); the search was also filtered to CC0, and the fetch script refused to download any page that did not show the CC0 link.
- The audio fetched was the Freesound HQ preview mp3 from the public CDN (the original download needs a login), decoded with ffmpeg. Raw downloads sit in `C:\tmp\props-sounds-raw\<family>\<id>.mp3` and were only read by ffmpeg, never executed.
- No Pixabay, Mixkit, ZapSplat, Sonniss, CC-BY, NC, SA or ND material is used.

## What was done to every file

Mono, 44.1 kHz. Trimmed from about 25 ms before the event onset to where the tail has decayed 40 dB (kept inside 0.45-1.2 s), 3 ms fade in, cosine fade out (up to 150 ms), plain gain to the family loudness target, a peak limiter (ffmpeg `alimiter`, ceiling -2.2 dBFS, only catches the highest spikes) and Vorbis q5 encode. Gain was iterated until the encoded file measured on target.

Loudness target per family (loudest 100 ms RMS, dBFS): wood -16, metal -16, glass -18, clay -18, splash -17.5, stone -20.5. Glass and stone are spiky or noisy, so matching them to -16 would need 6-9 dB of limiting and sound crushed. The existing Freesound surface sounds sit at -13 to -18.

## Measurements

- **peak**: sample peak of the encoded ogg, must be <= -1.2 dBFS.
- **100ms RMS**: loudest 100 ms RMS of the encoded file (the loudness-match metric, within +-2 dB per family).
- **LUFS**: ebur128 integrated loudness of the clip, for reference.
- **noise floor**: quietest 5% of 20 ms RMS blocks of the whole source with the applied gain added, must be <= -55 dBFS (digital silence in the source shows as a very low value).
- **gain**: gain applied before the limiter, must be <= +25 dB.
- **clipping**: sources were rejected when a run of 4 or more consecutive samples sat at >= 0.985 of full scale. Every encoded file has no such run.
